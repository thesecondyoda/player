# مشروع لوحة التحكم ونظام إدارة المستخدمين

مشروع ويب متكامل يتضمن واجهة أمامية (HTML5, CSS3, JavaScript) وهيكل قاعدة بيانات SQL.

## محتويات الملف:
- `index.html`: الصفحة الرئيسية / لوحة التحكم.
- `styles.css`: تنسيقات التصميم المتجاوبة (Responsive Design).
- `script.js`: ملف الجافاسكريبت للتفاعل الديناميكي.
